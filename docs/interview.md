# 面试讲稿与高频追问

## 30 秒项目介绍

> 我做了个 MCP 网关，基于 Spring AI 2.0。解决的核心问题是：AI 客户端要调用公司十几个业务服务，如果每个服务都单独对接，客户端要维护一堆连接。网关让客户端只连一个端点，对客户端它是 MCP Server，对下游它是 MCP Client，下游对客户端透明。
>
> 我做的东西里，最难的有三块：一是命名空间路由——所有下游工具统一成 `alias__tool` 的名字，包括白名单、schema 改写、冲突 fail-fast；二是熔断降级——单个下游挂掉不能拖垮整个网关；三是双链路鉴权——内外网两套部署共用一份代码，靠 CallerContext 统一身份。另外还做了限流、指标、审计落库。

## 高频追问清单

### Q1：为什么网关要同时是 MCP Server 和 MCP Client？两个角色各自的职责边界？

**答：** 对上游（AI 客户端）它是 Server，暴露统一端点和工具列表；对下游（业务系统）它是 Client，主动连接各个 MCP Server。职责边界：Server 侧负责鉴权、路由、熔断、限流；Client 侧负责连接下游、转发调用、透传参数。网关是"翻译官"——把多个下游的工具翻译成一个统一的工具列表。

### Q2：为什么用 `{alias}__{toolName}` 双下划线命名？

**答：** MCP 协议规定工具名字符集是 `[a-zA-Z0-9_-]`，不能用点号或斜杠。双下划线是唯一能清晰区分命名空间和工具名的方式——下游工具名本身可以含单个下划线，按第一个 `__` 切分就不会冲突。备选方案有点号、斜杠、JSON 包一层，但都不符合 MCP 命名规范。

### Q3：熔断阈值 50%/5 次是怎么定的？半开为什么是 30 秒？

**答：** 最小 5 个请求是避免偶发波动误判——2 次失败就熔断太敏感。30 秒窗口是短时间内连续失败才说明下游真挂了，不是网络抖动。半开 30 秒是给下游恢复时间——挂了不可能瞬间好，30 秒是个合理的重试间隔。这些都是 Resilience4j 之类成熟框架的默认值。

### Q4：为什么 DOWN 时工具不继续留在列表里？

**答：** AI 客户端看到工具存在就会反复尝试，藏起来让它更快改走其他路径。保留并报错会浪费上下文窗口——客户端知道工具存在但调不通，会一直重试。

### Q5：为什么 list_tools 不带完整 schema？

**答：** 下游 tool 多了全量 schema 吃大模型的上下文窗口。先 list 看名字和描述，再 describe 看完整 schema——按需加载，省 token。

### Q6：审计为什么只记字段名和长度，不记 arguments？

**答：** AI 调用参数可能含用户隐私——比如查客户信息，参数里有身份证号。审计只记字段名+长度，既知道调了什么，又不泄露内容。生产环境会改成脱敏后存（手机号中间星号那种）。

### Q7：限流为什么只对 tools/call 计量？

**答：** 协议握手（initialize、tools/list）是必要开销，限流会导致客户端连不上。只对实际工具调用限流，防止一个租户刷爆下游。

### Q8：多实例部署时，熔断状态和 Key 缓存在实例间怎么一致？

**答：** 诚实说——当前是单机内存实现，多实例下每个实例独立统计。演进方向：熔断状态存 Redis（Redisson 的 RRateLimiter），Key 表存 PostgreSQL + 5 分钟缓存刷新。但初版不做，因为十几个下游的规模单机够了。

### Q9：如果让你加"下游动态注册（服务发现）"，你会怎么设计？

**答：** 下游启动时注册到注册中心（Nacos/Eureka），网关监听注册事件，自动建立 MCP Client 连接，不用手动改配置。但当前是配置驱动，因为下游数量少（十几个），手动配置更简单可靠。

### Q10：网关是单点，怎么缓解？

**答：** 多实例部署 + 负载均衡。熔断状态和限流计数放 Redis。审计日志集中收集（ELK）。凭证管理用密钥管理服务（KMS），不硬编码在配置里。

## 决策记录

| 决策 | 一句话理由 | 备选方案 |
|---|---|---|
| `{alias}__{toolName}` 命名 | MCP 命名规范限制，双下划线能清晰切分 | 点号、斜杠、JSON 包一层 |
| 白名单才透传 | 下游发版新增的 tool 不应无声无息对外 | 全量透传 |
| 元工具不带完整 schema | 省 token，按需加载 | 全量返回 |
| 熔断 50%/5 次/30 秒 | 成熟框架默认值，避免误判 | 更敏感的阈值 |
| 同步写审计 | 初版简单，后续换队列异步 | 异步队列 |
| ApiKey 用 403 不用 401 | 不触发 OAuth 握手 | 401 + WWW-Authenticate |
